▤ Course catalog Restricted

Real course codes/titles, imported for reference. NOTE: the feature that once auto-corrected OCR results against this list is disabled — DVM's naming convention turned out not to reliably match what the real BITS ERP shows, so nothing currently reads this data automatically. Kept here in case a properly- verified use comes up later.
Current catalog
Paste a JSON array of course objects — each needs at least a "code" (e.g. from DVM's course-data JSON, using its "course_no" and "course_title" fields renamed to "code"/"title"). Importing REPLACES the entire catalog, it doesn't merge with what's already there.
Standard courses by program & semester
Shown to students on Profile as a reference only — this is NEVER used to check or modify a student's own uploaded timetable, only to display "here's what's typical for your program/semester." Paste a JSON object keyed like "A7|1" (program code, pipe, semester number 1-10), each mapping to an array of course codes. Importing REPLACES everything.
Section options (instructors, rooms)
Powers "Build your timetable" on Profile. Auto-refreshed nightly (see nightlySyncCourseData in Code.gs) — this manual import is for forcing an update right now instead of waiting. Paste an array of { code, title, lecture: [{sec, instructors: [...], room}], tutorial: [...], practical: [...] } — same shape DVM's own data uses. Importing REPLACES everything.
